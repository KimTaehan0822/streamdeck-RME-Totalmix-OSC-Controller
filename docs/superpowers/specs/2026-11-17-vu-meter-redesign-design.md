# VU 바늘 다시 설계

날짜: 2026-11-17 · 크기: 작은 변경 (짧은 설계)

## 왜
지금 VU 바늘은 dBu 기준(+4/+7/+10)으로 만들었는데, 실제 음악에서 TotalMix RMS(-17~-20 dBFS)보다 훨씬 높게 읽혀 끝까지 간다. 원인은 TotalMix OSC가 **피크** 값만 보내기 때문이다(아래 측정). 사용자는 VU를 되도록 정확하게, 기준을 분명히 밝힌 채로 다시 만들기를 원한다.

## 확인한 사실 (2026-11-17 측정, Babyface Pro FS, TotalMix Global OSC)
- OSC 레벨은 채널마다 `/level/{in,pb,out}/N` 값 하나뿐이고 **표본 피크(dBFS)**다. -18 dBFS RMS 사인파에서 -14.99가 온다. TotalMix 화면 레벨 미터가 RMS 모드여도 같다.
- OSC 설정에는 Send Peak Level Data, Peak Hold만 있고 RMS 옵션이 없다(설정 화면, 상세 설정, 실제 메시지 103종 확인).
- 값은 바뀔 때만 오고(Send changes), TotalMix 피크 미터의 하강(초당 약 20 dB)이 그대로 실린다. 초당 14~22개.
- 받은 값(중간값) − 실제 RMS(300 ms):

| 소리 | 차이 (dB) |
|---|---|
| 사각파 | 0 |
| 클리핑된 노이즈 | 1.9 |
| 사인파 (1 kHz·100 Hz, -10·-18 dBFS) | 3.0 |
| 화이트 노이즈 | 4.8 |
| 실제 음악 (두 곡, 강하게 압축된 곡) | 4.5~7 |
| 킥 드럼 같은 소리 | 8.3 |
| 핑크 노이즈 (-18·-28 dBFS) | 10.2 |
| 다이내믹이 큰 음악 같은 소리 | 11.4 |
| 말소리 같은 소리 | 14.5 |

- 받은 값의 출렁임으로 이 차이를 추정해 보았으나 관계가 없었다(출렁임 0인 소리끼리 0~4.8 dB, 출렁임과 차이가 같이 커지지 않음). 피크만으로는 소리마다 맞출 수 없다.
- 플러그인 자원: CPU 코어 하나의 약 1.1%(28코어 전체의 0.04%), 메모리 약 57 MB(음악 재생 중).

## 방법 (사용자가 고름)
| 방법 | 결과 |
|---|---|
| **고정 보정, 사용자가 값 결정** (선택) | 간단. 음악에 맞추면 음악은 ±2 dB, 말소리·노이즈는 높게 읽힘. 사용자가 자기 소리에 맞게 바꿀 수 있음 |
| 출렁임으로 적응 보정 | 측정 결과 관계가 없어 정확도가 나오지 않음 → 버림 |
| 플러그인이 Windows 오디오 장치에서 소리를 직접 받아 RMS 계산 | 플레이백·입력은 정확, 아웃풋은 불가능. 도우미 프로그램 필요. 사용자가 아웃풋도 중요해서 버림 |

## 정한 것 (사용자)
- **정렬:** 0 VU를 dBFS 값으로 정한다(DAW 방식). dBu 기준(+4/+7/+10)은 없앤다.
- **피크 보정:** 받은 피크에서 뺄 dB를 사용자가 정한다. 설정 화면에서는 "설명서 참고"로 안내하고, 위 측정표를 설명서(KO/EN/JA)에 싣는다.
- **글자:** 바늘이 가리키는 값(보정·평균 뒤)을 dBFS로 보인다.
- **기준 명시:** 설정 화면과 설명서에 적는다. 판 안에는 적지 않는다(디자인을 해친다, 2026-11-17 사용자 결정).
- **판 눈금:** 원래 VU 숫자(20, 10, 7, 5, 3, 0, 3)로 돌아간다.

## 내가 정한 것 (바꿀 수 있음)
- **0 VU 기준 목록:** -14 / -18 / -20 dBFS, 기본 -18. (DAW VU 플러그인에서 흔한 값. -14는 스트리밍 음량 기준에 가까움)
- **피크 보정 기본값:** 5 dB(음악 측정 기준). 입력 범위 0~15 dB, 0.5 단위. 숫자 칸 하나.
- **설정 위치:** 기존 "Meter design" 묶음 안, 다이얼·버튼 칸 아래에 "VU 0 VU 기준"과 "VU 피크 보정 (dB)" 두 칸. 플러그인 전체 설정(`vuReference`, `vuPeakOffset`)이고 VU 바늘 디자인에만 쓴다. 옆에 "VU 바늘에만 적용. 값은 설명서 참고" 안내.
- **설정 목록:** VU는 "VU needle" 하나로 합친다(`vu`). 예전 값 `vu4`·`vu10`이 저장돼 있으면 `vu`로 읽는다.
- **바늘 움직임:** 지금처럼 진폭 300 ms 평균(올라감·내려감 같음). 평균은 보정을 뺀 뒤의 값에 한다.
- **글자 자리:** 지금 소리 크기 글자가 있는 곳(세로 2키 아래)에 `-18.0 dBFS`처럼 보인다. 다른 화면은 지금처럼 페이더 값을 보이고, 판 안 기준 글자만 더한다.
- **VU 설정 칸:** 다이얼이나 버튼 중 하나라도 VU 바늘을 골랐을 때만 보인다(2026-11-17 사용자 요청).

## 하지 않는 것
- OSC로 RMS 받기(없음), 오디오 장치에서 직접 받기, 적응 보정, dBu 표시.
- 다른 플러그인(TOPPING, OBS) 복사는 이 작업에 넣지 않는다(2단계).

## 확인 방법
- 테스트: 보정 5 dB·기준 -18일 때 피크 -13 dBFS 입력이 바늘 0 VU, 글자 `-18.0 dBFS`. 보정·기준을 바꾸면 바늘과 글자가 따라 바뀜. 예전 `vu4`·`vu10` 설정이 `vu`로 그려짐. 설정 값이 비었거나 이상하면 기본값.
- 실제: 같은 음악에서 TotalMix RMS와 바늘 글자를 나란히 비교(사용자 확인).
- 릴리스 때 설명서·README 3개 언어에 측정표와 설정 설명 추가(사용자 규칙).
