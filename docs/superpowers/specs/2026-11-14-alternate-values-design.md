# 두 값 번갈아 모드 (Fader · Pan · FX 파라미터 키) 설계

날짜: 2026-11-14 · 크기: 작은 변경 (짧은 설계)

## 왜
버튼 하나로 볼륨(또는 팬, FX 값)을 두 값 사이에서 오가고 싶다. 예: 배경음악 -10 dB ↔ -30 dB. 지금은 '값으로 설정' 키를 두 개 놓아야 한다.

## 목표
- Fader 키, Pan 키, FX 파라미터 키의 모드 목록에 **두 값 번갈아**를 추가한다. 기존 '값으로 설정', '값만큼 조절'은 그대로 둔다.
- 설정 화면에 **값 1**, **값 2** 칸을 둔다. 값 1은 지금의 `value` 설정을 그대로 쓰고, 값 2는 새 설정 `value2`.
- 누를 때마다 **지금 값**을 보고 정한다: 지금 값이 값 2와 같으면 값 1로, 아니면 값 2로 보낸다.
  TotalMix에서 직접 움직였거나 플러그인이 다시 시작돼도 순서가 꼬이지 않는다.
- 키 상태 두 개(뮤트 키와 같은 방식): 지금 값이 값 2와 같으면 상태 2, 아니면 상태 1. 사용자가 스트림덱 앱에서 상태마다 다른 아이콘·제목을 정할 수 있다. 다른 모드에서는 늘 상태 1.

## 하지 않는 것
- '값으로 설정(토글)'(지금 값을 기억했다가 되돌리기)은 넣지 않는다(사용자 결정).
- 다이얼 액션(Pan 다이얼, FX 파라미터 다이얼)은 바꾸지 않는다.
- 지금 값을 모를 때(TotalMix 연결 전, 아직 값을 못 받음)는 값 2로 보낸다(값 2와 "같지 않음"으로 본다).

## "같은 값"의 기준
TotalMix가 돌려주는 값은 보낸 값과 아주 조금 다를 수 있다(예: -20 → -19.97 dB). 키별로 이만큼 차이까지는 같다고 본다:
- Fader, 단위 dB: 0.2 dB. 단위 선형(0~1): 0.005.
- Pan(-100~100): 1.
- FX 파라미터: 값 2 크기의 1% 또는 0.01 중 큰 쪽. (FX 값은 단위가 제각각이라(초, ms, dB, %) 리버브 시간 1.5초 같은 작은 값도 구분되게 고정 0.5 대신 0.01을 바닥으로 쓴다.)

## 방법
| 방법 | 장점 | 단점 |
|---|---|---|
| **세 키가 공유하는 키 동작에 모드 하나 추가** (선택) | 누르기 처리가 한 곳. Fader·Pan은 같은 부모 클래스, FX 키는 같은 규칙을 따로 한 줄로 | FX 키는 부모가 달라 두 군데 |
| 키마다 따로 구현 | 서로 영향 없음 | 같은 규칙이 세 번 |

## 바뀌는 곳
- `src/actions/faders.ts` (Fader, Pan 키), `src/actions/gain-fx.ts` (FX 파라미터 키): 모드, 지금 값 비교, `keyState`.
- `manifest.json`: 세 액션에 상태 두 개(`States` 2개 + `DisableAutomaticStates`).
- `ui/fader.html`, `ui/fx.html`: 모드 목록과 값 2 칸. `ui/common.js`: 번역(`Alternate two values` → `두 값 번갈아` / `2つの値を交互に`, `Value 2` → `값 2` / `値 2`, 모드가 번갈아일 때 `Value` 칸 이름은 `Value 1` → `값 1` / `値 1`).
- 이미 놓아 둔 Fader·Pan·FX 키는 상태 두 개 아이콘을 쓰려면 지웠다가 다시 놓아야 한다(뮤트 키 때와 같음). 다시 놓지 않아도 동작 자체는 된다.
