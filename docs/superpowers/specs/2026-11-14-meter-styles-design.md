# 레벨미터 디자인 선택 (토탈믹스 옛·새 디자인 추가) 설계

날짜: 2026-11-14 · 크기: 작은 변경 (짧은 설계)

## 왜
스트림덱의 레벨미터를 토탈믹스 화면과 같은 모양으로 보고 싶다. 토탈믹스에는 옛 디자인과 새 디자인이 있다(Window → Toggle Old-New Design). 지금 플러그인 디자인도 계속 쓸 수 있어야 하므로 세 가지 중에서 고른다.

## 목표
- 미터 디자인 세 가지: **플러그인 기본**(지금 모양, 기본값), **토탈믹스 옛 디자인**, **토탈믹스 새 디자인**.
- 선택은 플러그인 전체에 한 번만 한다. 설정 화면의 언어 설정처럼 접힌 칸("미터 디자인")에 드롭다운으로 둔다.
- 미터가 나오는 세 곳에 모두 적용한다: 다이얼 화면(VU 다이얼, 게인 다이얼), 키 미터, 버튼 페이더 2키.
- 토탈믹스 디자인 두 가지는 토탈믹스 눈금을 따른다(위쪽 10 dB를 넓게). 페이더를 나타내는 파란 선도 같은 눈금 위에 그린다.
- 토탈믹스 디자인 두 가지에는 눈에 보이는 눈금을 그린다: 0·6·10·20·40·60 dB 자리에 막대를 가로지르는 옅은 선.
  숫자는 자리가 있는 곳에만 쓴다: 다이얼 화면은 막대 아래, 세로 버튼 페이더는 막대 왼쪽(6은 10과 겹쳐서 선만). 키 미터와 가로 버튼 페이더는 선만.

## 하지 않는 것
- 클립 표시 칸, 칸 사이 가는 선, 피크 홀드 표시: 이번에는 넣지 않는다(테스트에서 제대로 확인하지 못한 부분).
- 버튼마다 다른 디자인을 고르는 기능.
- 글자, 음소거 빗금, 파란 페이더 선 모양은 세 디자인 모두 지금과 같다.

## 측정값 (2026-11-14, Babyface Pro, 1 kHz 테스트 소리 -30 → 0 dBFS)
토탈믹스 눈금 (0 dB 높이를 1로 볼 때 각 dB의 막대 높이):
-65 → 0, -30 → 0.39, -20 → 0.51, -15 → 0.59, -12 → 0.65, -9 → 0.71, -6 → 0.79, -3 → 0.90, 0 → 1.
플러그인에서는 0 dB를 막대 길이의 90%에 두고, 나머지 10%는 +6 dB까지 페이더 선이 갈 자리로 쓴다(+6 dB → 100%, 이 구간은 측정하지 않아 직선으로 이음).

옛 디자인: 바탕 `rgb(31,41,48)`. 막대 색은 위치(dB)에 따라 부드럽게 바뀐다.
-65 `(133,255,3)` · -30 `(163,255,3)` · -20 `(185,255,1)` · -12 `(222,255,1)` · -8 `(249,250,0)` · -6 `(253,225,0)` · -4 `(253,183,0)` · -3 `(253,133,1)` · -1 `(253,80,1)` · 0 `(253,57,1)`.

새 디자인: 바탕 `rgb(50,58,64)`. 구간마다 한 가지 색이다.
-3 dB 아래 초록 `(25,209,32)`, -3 ~ -0.3 dB 노란 주황 `(255,189,32)`, 그 위 빨강 `(255,71,27)`.
막대 끝 2픽셀은 더 밝게: 초록 구간 `(12,255,16)`, 노랑 구간 `(255,254,16)`, 빨강 구간은 빨강 그대로.

## 방법 (고른 것)
| 방법 | 장점 | 단점 |
|---|---|---|
| **미터 그리는 곳에 디자인 값 하나를 두고, 막대·색·눈금만 디자인별로 다르게** (선택) | 바뀌는 곳이 `render/meter.ts` 한 파일. 글자 배치 그대로 | 디자인 값이 모듈 전체에 걸린 상태값이 됨 |
| 그리는 함수마다 디자인을 인자로 넘김 | 상태값 없음 | 액션 코드 여러 곳(다이얼, 키, 페이더, 게인)을 다 고쳐야 함 |

전체 설정 하나라서 한 곳에 두는 쪽을 골랐다.

## 동작
- 전체 설정 값 `meterStyle`: `plugin`(기본) · `classic`(옛) · `modern`(새). 모르는 값은 `plugin`.
- 플러그인은 전체 설정을 받을 때마다 미터 디자인을 바꾼다. 연결 설정이 아니므로 연결을 다시 시작하지 않는다.
- 키는 2초마다 다시 그려지므로(지금 있는 동작), 바꾼 디자인은 늦어도 2초 안에 모든 키에 보인다.
- 설정 화면 글자는 한국어·일본어로도 나온다(기존 번역표에 추가).

## 만드는 사람에게 맡기는 것
- 막대·색 계산 함수의 이름과 나누는 방식.
- 테스트에서 색과 위치를 확인하는 방법.
