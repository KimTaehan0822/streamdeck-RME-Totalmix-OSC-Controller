# 미터 디자인 8가지 (오디오 플러그인 공용) 설계

날짜: 2026-11-16 · 크기: 프로젝트 (전체 설계)

## 왜
사용자가 만든 오디오 컨트롤 플러그인 네 개(RME TotalMix, TOPPING E2x2 OTG, OBS, 프릭샷플러스)는 미터를 저마다 다르게 그린다. 어느 플러그인에서든 서로의 미터 모양과, 새로 만드는 두 모양(큰 dB 숫자형, VU 바늘형)을 골라 쓰고 싶다.

## 순서 (사용자 결정)
1. **1단계 (이 설계의 범위):** TotalMix 플러그인(`streamdeck-rme-totalmix`)에서 8가지 디자인을 모두 만든다. 다른 플러그인 모양은 그 저장소의 그리기 코드를 옮겨 와서 만든다.
2. **2단계 (나중, 별도 설계):** 같은 디자인 코드를 TOPPING(`streamdeck-topping-e2x2`), OBS·프릭샷플러스(`streamdeck-obs-audio`) 저장소에 복사하고, 플러그인마다 채널 이름·음량 표시·페이더 위치가 이상하지 않은지 따로 검토한다.

## 목표 (1단계)
- 설정 화면의 기존 **Meter design** 목록을 8개로 늘린다. 플러그인마다 따로 고른다(전체 설정 `meterStyle`, 사용자 결정).

| 값 | 이름 (설정 화면) | 한국어 / 일본어 | 출처 |
|---|---|---|---|
| `plugin` | Plugin (default) | 플러그인 기본 / プラグイン標準 | 지금 TotalMix 기본 |
| `classic` | TotalMix classic | 토탈믹스 옛 디자인 / TotalMix 旧デザイン | v1.1.0 |
| `modern` | TotalMix new | 토탈믹스 새 디자인 / TotalMix 新デザイン | v1.1.0 |
| `topping` | TOPPING | TOPPING / TOPPING | `streamdeck-topping-e2x2/src/render/meter.ts`, `theme.ts` |
| `obs` | OBS standard | OBS 표준 / OBS 標準 | `streamdeck-obs-audio/src/render/meter.ts` (style `standard`) |
| `obs-wide` | OBS wide | OBS 와이드 / OBS ワイド | 같은 파일 (style `wide`) |
| `big` | Big number | 큰 dB 숫자 / 大きな dB 表示 | 새로 만듦 |
| `vu` | VU needle | VU 바늘 / VU 針 | 새로 만듦 |

- **화면 전체 모양까지** 그 디자인을 따른다(사용자 결정): 이름 위치와 판, 페이더 표시(파란 선, TOPPING 손잡이 등), 글자 배치, 눈금, 색.
- 적용되는 화면 세 가지(사용자 결정): **다이얼 화면**(VU Dial, Gain Dial, 200×100), **Fader 키**(값 키의 미터 부분 또는 키 전체, 144×144), **버튼 페이더 2키**(Fader(2-Button), top/bottom/left/right).
- 고르면 다음 다시 그리기(2초 이내)부터 바뀐다. 연결은 다시 시작하지 않는다(v1.1.0과 같음).

## 하지 않는 것
- 주파수 막대(스펙트럼): TotalMix OSC에 주파수별 데이터가 없다. 가짜로 흉내 내지 않는다.
- 2단계(다른 저장소 복사)는 이 설계에 넣지 않는다. 다만 1단계 코드는 그대로 복사해 쓸 수 있게 만든다(아래 "구조").
- 키마다 다른 디자인 고르기.

## 지금 모양 (목업 승인: 2026-11-16)
- 기존 6가지: 세 저장소의 현재 그리기 결과를 같은 소리로 나란히 그린 비교 이미지를 사용자가 봤다.
- 새 2가지(사용자 "이 방향 좋아요"):
  - **큰 dB 숫자형:** 얇은 큰 숫자(Segoe UI 300)로 페이더 값, 아래에 가는 L/R 막대 두 줄(청록 `rgb(40,150,190)` → `rgb(90,200,200)` → 노랑 `rgb(240,220,80)` 그라데이션, 바탕 `#1d2a30`, -60~0 dBFS 직선). 다이얼: 왼쪽 위 이름(회색), 오른쪽 위 소리 크기. Fader 키: 위 이름, 가운데 큰 숫자, 아래 막대. 2키: 위 키 이름+큰 숫자, 아래 키 막대+소리 크기.
  - **VU 바늘형:** 호박색 판(방사 그라데이션 `#ffe9a8` → `#f2b54a` → `#9a5a12`, 테두리 `#3a2608`), 눈금 20·10·7·5·3·0·3(0부터 빨강 `#c0291b`), "VU" 글자, 검은 바늘. 바늘은 L·R 중 큰 값. 다이얼: 왼쪽에 이름과 페이더 값, 오른쪽에 VU 판. Fader 키: 위 이름, 가운데 VU 판, 아래 페이더 값. 2키: 위 키 이름+페이더 값(큰 숫자), 아래 키 VU 판+소리 크기.
  - 목업 코드(참고용, 그대로 옮기지 않음): 세션 scratchpad `gallery/new-designs.mjs`.

## 정해 둔 값 (내가 정함, 바꿀 수 있음)
- **VU 기준:** 0 VU = -12 dBFS (목업과 같음). 눈금 위치는 전통 VU 눈금 비율(-20:0, -10:0.17, -7:0.29, -5:0.38, -3:0.5, -2:0.56, -1:0.63, 0:0.71, +1:0.79, +2:0.88, +3:1). +3 VU를 넘으면 끝에 멈춘다.
- **VU 바늘 움직임:** 실제 VU처럼 천천히 따라가게(상승·하강 약 300 ms) 한다. 키 그림은 지금처럼 최대 25회/초(REDRAW_MS 40)까지만 바뀐다.
- **음소거:** 모든 디자인에서 지금처럼 MUTED(빨강)와 흐린 미터. 큰 숫자형은 숫자 대신 MUTED, VU형은 판을 흐리게. 페이더를 막 움직였을 때(peek)는 MUTED 대신 페이더 값.
- **TOPPING 디자인의 눈금:** TOPPING처럼 0 dB를 0.8에, +12 dB를 끝에 둔다. TotalMix 페이더는 +6 dB까지라 그 아래에 멈춘다.
- **OBS 디자인의 눈금:** OBS처럼 바닥(-60 dB 기본)~0 dB, 페이더 0 dB를 끝으로 본다. TotalMix 페이더가 0 dB보다 크면 끝에 멈춘다. 피크 홀드는 TotalMix 데이터에 없으니 그리지 않는다(필드는 둔다).
- **Gain Dial:** 페이더 자리에 게인(직선 0..1)을 쓰는 기존 동작(`linearFader`)을 모든 디자인에서 지킨다. 큰 숫자형은 "Gain +12.0 dB" 문구를 그대로 큰 숫자 자리에 쓴다.
- **배지(48V 등)와 사용자 제목:** 지금처럼 동작해야 한다. 배지는 다이얼 화면 오른쪽 위, 자리가 겹치는 디자인(큰 숫자형의 소리 크기)은 배지를 먼저 보이고 소리 크기를 뺀다. Stream Deck 제목이 있으면 그 디자인의 이름 칸을 비운다(v1.2.0과 같음).

## 구조
| 방법 | 장점 | 단점 |
|---|---|---|
| **공통 입력 형식 + 디자인별 파일** (선택) | 2단계에서 폴더째 복사 가능. 플러그인은 자기 데이터를 공통 형식으로 바꾸기만 함 | 기존 TOPPING·OBS 코드의 입력을 공통 형식에 맞춰 고쳐야 함 |
| 지금 `meter.ts`에 디자인 분기를 계속 추가 | 바뀌는 파일이 적음 | 한 파일이 커지고, 다른 저장소로 옮기기 어려움 |

- 새 폴더 `src/render/meters/`. 이 폴더는 플러그인 고유 코드(TotalMix 상태, 액션)를 불러오지 않는다(2단계 복사용). 필요한 글자 도우미(`plainText`, `fitText` 등)도 이 폴더 안에 둔다.
- 공통 입력(이름은 만드는 사람이 정함): 이름, 왼쪽·오른쪽 소리(dBFS, 소리 없음은 -∞), 페이더(dB 또는 직선 위치), 페이더 글자, 소리 글자, 음소거, peek, 배지, 피크 홀드(선택), 강조색(선택, TOPPING 믹스 색), 오버레이.
  - 지금은 값이 "막대 비율"(dbToBar, -65~+6 직선)로 넘어온다. 공통 입력은 dB로 바꾼다. 디자인마다 자기 눈금으로 변환한다.
- 디자인마다 세 화면 함수: 다이얼 화면, Fader 키(값 키 전체), 2키 한 쪽(역할 top/bottom/left/right).
- 기존 `src/render/meter.ts`(plugin/classic/modern)의 출력은 지금과 한 글자도 달라지지 않아야 한다(기존 테스트 통과).

## 확인 방법
- 디자인 8 × 화면 3 × (보통, 음소거, peek, 설정 미완성) 그림을 테스트에서 만들어 SVG로 저장하고, 글자 잘림("…")과 NaN이 없는지 확인.
- 실제 스트림덱에서 8가지를 차례로 바꿔 보고 사용자 확인.
- 릴리스 때 설명서·README 3개 언어와 버전 함께 갱신(사용자 규칙).

## 만드는 사람에게 맡기는 것
- 공통 입력의 정확한 이름과 형태, 파일 나눔, 옮겨 온 TOPPING·OBS 코드를 공통 입력에 맞추는 방법.
- 새 두 디자인의 세부 픽셀 위치(목업 기준으로 다듬기, 이름 잘림·바늘이 VU 글자 위를 지나는 문제 해결).
- 가로 2키(left/right)에서 새 두 디자인의 배치(목업은 세로만 있음): 왼쪽 키 = 위 키 내용, 오른쪽 키 = 아래 키 내용으로 시작.

## 구현하며 정한 것 (2026-11-16, 사용자가 "검토 없이 바로 다 만들어" 요청)
- 기존 세 디자인(plugin/classic/modern)은 출력이 그대로여야 해서 `src/render/meter.ts`에 그대로 두었다. 새 폴더 `src/render/meters/`에는 TOPPING, OBS 표준·와이드, 큰 숫자, VU 다섯 가지만 있다. 2단계에서 세 디자인도 이 폴더로 옮겨야 다른 플러그인에서 고를 수 있다.
- `src/render/meters/`는 `../svg.js`의 글자 도우미만 쓴다(`textWidth`를 svg.ts에 추가). 2단계에서 각 저장소의 svg.ts가 같은 함수를 가져야 한다.
- OBS 디자인의 바닥은 -60 dB 고정(설정 없음). 피크 홀드는 그리지 않는다. 게인 다이얼의 직선 게인은 -60~0 dB 눈금 위에 펼친다.
- Fader 키의 음소거: 새 다섯 디자인은 값 자리에 MUTED를 보인다. 기존 세 디자인은 그대로(값 표시).
- VU 바늘은 키마다 진짜 VU처럼 평균을 따라간다(2026-11-17 사용자 요청). TotalMix 레벨(피크에 가까움)을 진폭으로 바꿔 300 ms 시간 상수로 평균하고, 올라갈 때와 내려갈 때 같다. 바늘이 아직 움직이는 중이면 새 레벨이 오지 않아도 40 ms마다 다시 그린다. 1초 넘게 안 그려졌으면 바로 그 자리로 간다.
- TOPPING Fader 키·2키, 큰 숫자 가로 2키의 빈칸을 줄였다(2026-11-17 사용자 요청): 세로 2키 막대를 넓고 길게, 가로 2키 이름판·값 글자를 크게.
- VU 기준 레벨 세 가지(2026-11-17 사용자 요청): RME 출력은 기본(Hi Gain)에서 0 dBFS = +19 dBu. `vu` = 0 VU +7 dBu(-12 dBFS, 처음 만든 것), `vu4` = +4 dBu(-15 dBFS), `vu10` = +10 dBu(-9 dBFS). 판 모양은 같고 바늘 위치만 다르다.
- TOPPING 세로 2키 막대 폭은 처음 크기로 되돌리고 길이만 늘렸다. 가로 2키 글자는 처음 크기로 되돌리고, 왼쪽 키의 소리 크기 글자를 이름판 아래(38)와 손잡이 위(96) 사이 가운데(67)에 둔다. 오른쪽 키의 페이더 값·MUTED는 처음 자리(50) 그대로.
- VU 디자인의 판 눈금 숫자는 그 기준의 dBu로 적고(0 VU = 기준 dBu, 판 글자 "dBu"), 소리 크기 글자는 그 기준의 VU 값(예: +3.0 VU)으로 보인다(2026-11-17 사용자 요청). dBu 숫자가 길어서 넓은 판은 -20·-10·-5·0·+3 VU 자리, 좁은 세로 2키 판은 -10·-5·0 VU 자리에만 숫자를 쓴다.
- 설정 목록의 VU는 전압 순서(+4, +7, +10 dBu)로 놓는다.

## 목록 이름 바꾸기 (2026-11-17 사용자 결정, 아직 적용 전)
다른 회사·프로젝트 이름(상표)을 그대로 쓰지 않도록, 패러디 느낌의 이름으로 바꾼다. 설정에 저장되는 값은 그대로 둔다(기존 설정 유지).

| 값 | 지금 이름 | 새 이름 |
|---|---|---|
| `topping` | TOPPING | Topping on Plate |
| `obs` / `obs-wide` | OBS standard / OBS wide | On Air / On Air Wide |
| `classic` / `modern` | TotalMix classic / TotalMix new | Mix Studio Classic / Mix Studio Modern |
| `big` | Big number | Big number |
| `vu` | VU needle | VU Needle Drop |

`Open Broadcast`는 OBS 정식 이름(Open Broadcaster Software)과 거의 같아서 뺐다. 2단계(다른 플러그인 복사) 때 TotalMix 플러그인의 설정 화면·README·설명서도 같이 바꾼다.
